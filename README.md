# Top 10

Jogo de adivinhar listas: escolha um desafio (ex.: "Os 10 estados brasileiros mais populosos") e tente acertar os 10 itens. Cada erro custa uma vida, e você tem 3.

## Como jogar

Abra o `index.html` no navegador. Não precisa instalar nada.

Os palpites não diferenciam maiúsculas nem acentos ("sao paulo" vale "São Paulo"), e siglas são aceitas quando cadastradas (ex.: "SP").

## Adicionar uma lista

Edite `data.js` e acrescente um bloco ao array `LISTS` com `id`, `title`, `source` e 10 `items` em ordem. Cada item pode ter `aliases` com outras grafias aceitas.

## Publicar

Para jogar online, ative o GitHub Pages em **Settings → Pages** e selecione a branch `main`.
